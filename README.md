# 速片工厂 · 数字人口播

基于 [MoneyPrinterTurbo](https://github.com/harry0703/MoneyPrinterTurbo) 的 Creator 增强版：按视频目的创作，复用客户资料，从文案、配音和素材生成成片。

## 下载与打开

**Windows 10/11 64位用户优先下载 [Releases 中的 Windows 双击启动包](https://github.com/iudengfeng/MoneyPrinterTurbo-Creator/releases/latest)。**

1. 完整解压到可写文件夹，路径可以包含中文或空格。
2. 双击 **启动数字人口播.cmd**。第一次联网自动准备应用专用运行环境，完成后打开浏览器。
3. 在四列首页导入或编辑文案，选择音色和形象，生成语音、口播与成片；已有口播视频也可以直接导入处理。

无需先安装 Python、Node.js 或原客户端。首次准备会下载组件，请保持窗口打开；之后复用缓存。不要在压缩包内运行，也不要只复制一个启动文件。源码 ZIP 同样提供入口。

基础图文视频可先用现成文案和标准配音。标准配音需要联网；AI 写稿需要用户自己的模型配置。数字人和本机声音克隆需要接入 Duix、适合的硬件和自己的形象／音色；发行包不含人物视频、客户样音、Duix 模型或任何人的 API Key。发布需要用户登录并确认。

安装遇到问题，双击“检查运行环境.cmd”，查看 storage/creator/logs/runtime-health.json。[详细安装说明](docs/creator-install.md) 列出环境、数据与组件来源。

## 四列首页

“数字人口播”默认打开四列工作台，文案、口播、视频处理和发布制作同时可见。浅色与深色主题可切换；任务中心显示后台进度。“速片工厂”保留原快速视频制作入口。

| 首页列 | 操作与结果 |
| --- | --- |
| 01 IP深度学习 | IP资料与参考库、视频文案提取、编辑文案、撰写文案与AI洗稿 |
| 02 口播制作 | 选择音色、生成与试听语音、选择形象、生成口播、导入口播视频 |
| 03 视频处理 | 画面设置、字幕与关键词、背景音乐、HyperFrames包装、生成与预览成片 |
| 04 发布制作 | 编辑标题与标签、生成与下载封面、管理账号、准备预览后逐账号确认发布 |

发布实际接入**抖音和小红书**；快手、视频号显示为待接入且不可选择。“定时发布”目前下载手动发布清单，不会建立自动发布任务。侧栏的图像与视频生成入口使用已配置的服务或转到速片工厂，需要对应的模型和接口，不表示下载后已具备全部AI生成能力。

作品库、客户／品牌档案和原有独立工具继续保留。内部作品流程仍按文案、声音、画面、成片、发布资料五个阶段保存，四列首页共用这些真实结果；尚未完成的中间画面不会冒充成片供下载或发布。

创作中心保留产品服务、活动、专业知识、案例反馈、个人形象、素材快剪六种目的。客户档案说明提供什么、面向谁、特点和期望行动，保存后反复使用。门店、电商、服务商及知识创作者共用同一套流程。十二个内容模板提供推荐、备选和明确标示的示例，示例不作为客户事实。

可一键成片或分步制作。作品保留输入与阶段结果，中断后复用有效结果，修改设置仅重做受影响的部分。旧作品保留当时的客户资料，不因全局档案更新自动改变价格、地址或定位。

目标时长用于控制写稿篇幅，真实配音决定长度。人物动作默认不循环，短人物镜头配合素材或图文卡，完整配音及字幕时间轴保留。全程人物需要足够长的参考视频。

## 使用条件

- 素材匹配使用文件名和用户标签；知识讲解缺素材时可用图文卡，商品介绍和混剪需要真实素材。
- Whisper在本机识别，模型首次使用时下载；标准配音使用联网服务。
- 参考库读取已配置的公开网页或用户资料，不模拟热榜。缺失的互动数据显示“未取得”，需要登录或验证码时停止自动读取。
- 保存样音不等于本机声音训练完成，自己的声音由可用的Duix或配置的服务提供。
- 发布必须预览和确认，提交不明确不自动重发；不采集自己作品的发布后数据，不承诺平台不标注AI。
- 发行包不包含微软／苹果字库和未知授权音乐，提供Noto Sans SC及OFL许可，背景音乐默认不加。

## 开发与许可证

Python依赖由pyproject.toml和uv.lock固定，Node依赖由两个组件的package-lock.json固定。首启准备独立Python3.11、Node、FFmpeg／FFprobe及应用浏览器，下载地址与SHA-256见scripts/creator/runtime-manifest.json。FFmpeg由用户首次启动从官方下载，不作为本仓库的MIT文件重新分发。

项目代码保留MoneyPrinterTurbo的 [MIT许可证](LICENSE) 和原版权声明，第三方组件许可独立适用。[组件来源与许可](docs/creator-third-party.md) · [上游README快照](README-upstream.md)

个人config.toml、客户数据、登录目录、用户素材、音色和模型缓存不提交到GitHub。测试使用隔离目录、模拟发布与本机媒体；模拟提交不代表真实发布。
