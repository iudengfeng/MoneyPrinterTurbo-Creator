# MoneyPrinterTurbo Creator

基于 [MoneyPrinterTurbo](https://github.com/harry0703/MoneyPrinterTurbo) 扩展的本机创作工作台，把选题、口播稿、配音、数字人、模板剪辑、标题封面和发布准备串成可编辑的流程。

这是社区增强版，原视频制作入口保留。项目发布的是源代码；模型、视频、账号登录目录和个人配置均由使用者在本机准备。

## 创作流程

| 步骤 | 已实现的功能 |
| --- | --- |
| 选题和文案 | 账号定位、参考文案库、关键词选题、AI 拓展、仿写与原创、编辑和保存稿件 |
| 配音 | Edge 中文音色、完整配音与短试听、语速调整、Duix 已有音色、可配置的 VoxCPM 云端克隆 |
| 数字人 | 复用本机 Duix 人物和引擎，使用确认后的完整配音生成口播视频 |
| 模板剪辑 | Whisper 词时间字幕、四种样式、画幅调整、调色、背景音乐、定时画中画、Remotion 渲染和 FFmpeg 音轨合成 |
| 标题和封面 | AI 候选标题、正文和话题、视频真实截帧封面、四种排版、封面上传及历史素材恢复 |
| 发布中心 | 抖音与小红书独立账号目录、扫码登录、各账号独立文案、本地预览、视频封面文字 ZIP 导出、逐项确认发布 |

发布预览保存当时的文件和文字，后续修改不会改变已有预览。浏览器发布通过受限 Agent、官方 Playwright MCP 和独立账号浏览器执行；用户确认才会上传，提交结果不明确时阻止直接重发。

## 安装和使用

[安装说明](docs/creator-install.md) 包含源码环境和 Windows 便携版两种启动方式。

[创作工作台使用说明](docs/creator-workspace.md) 介绍每个步骤、依赖、数据位置和功能限制。

运行环境以 Python 3.11、Node.js 22 或更新版本及 FFmpeg 为基线。已在 Windows、Python 3.11、Node.js 24 和 Microsoft Edge 上验证。数字人生成另外需要本机 Duix、Docker 和对应模型；本仓库不包含这些模型或容器数据。

## 使用边界

- 没有抖音开放平台凭证时，使用网页搜索和自己的参考库；AI 建议标明来源，不模拟实时播放量或爆款榜。
- 分享链接可能受平台登录和下载限制影响，解析失败可上传本地音视频。
- 声音克隆需要可用的 Duix 音色或已配置的云端服务；保存样音不等于已完成本机克隆。
- 标题与文案生成使用自己配置的模型服务。确认浏览器发布时，任务文案和平台页面信息会交给该模型协助操作。
- 已实测抖音扫码后的登录复用和官方上传页识别；真实作品上传、提交和审核仍需按平台页面验证。小红书真实账号流程尚未实测。
- 不提供“平台不标 AI”保证；发布声明和平台规则以实际页面为准。

## 数据与验证

个人配置保存在本机 `config.toml`，创作数据和账号专用浏览器位于 `storage/creator`，均不进入 Git。不要把配置、声音样本、视频、数据库、模型或账号登录目录提交到公共仓库。

目前创作模块的 Python 检查 251 项通过，浏览器策略检查 11 项通过。已验证真实配音、数字人口播、字幕和音轨合成、封面生成、素材包内文件一致性，以及本地 MCP 登录和发布模拟流程。模拟提交不代表真实平台作品已发布。
