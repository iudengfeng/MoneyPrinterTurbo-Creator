# 创作中心：一键成片与分步制作

数字人口播现在默认展示四列首页：IP深度学习、口播制作、视频处理、发布制作。同屏完成文案编辑、配音与口播、字幕和音乐处理、封面与发布预览；“生成成片”可以继续准备所需的前置阶段。原有创作中心保留视频目的、客户／品牌档案、内容模板和分步设置，两种入口使用同一个作品任务。

首页是四列布局，内部作品仍按下面五个阶段保存与恢复。外部发布仍需逐账号确认；快手、视频号尚未接入，定时按钮只导出手动清单。

## 客户／品牌档案与内容目的

创作中心提供六种目的：介绍产品或服务、推广活动、分享专业知识、展示案例或客户反馈、打造个人形象、用已有素材快速成片。目的决定内容结构，行业用于调整表达；不会把客户限制在餐饮等单一行业。

客户／品牌档案先说明提供什么、面向谁，再填写特点和期望观众采取的行动。特点或行动尚未确定时可留空，软件不会补造客户事实。档案名称可自行命名；门店地址与营业时间、商品价格与购买入口、服务范围与真实案例、专业领域与内容风格按客户类型补充，保存后可反复选择。

档案资料与发布账号分别保存。每份作品固定保存本次选用的档案资料；修改全局档案不会自动替换旧作品中的价格、地址或定位。创作时明确选取新的档案版本才会用于本次内容，既有账号定位及作品保留。

每种视频目的提供推荐和备选结构，共十二个内容模板。模板展示结构、建议素材和标明“示例”的口播片段，示例不会自动填入客户档案或写稿事实。真实案例、评价、价格、活动日期和人物经历都需要客户实际提供。

可选择30、60、90或120秒目标时长。目标用于“帮我写稿”时估算篇幅，最终时长取决于真实配音；已有文案不会被自动截短或通过循环画面强行补时。制作方式由目的及已选素材推荐，知识讲解、素材混剪、商品介绍和数字人口播仍可在更多设置中调整。素材快剪仍需上传真实图片或视频，并提供简短文案或有效配音。

## 五步操作

1. **选题与文案**：直接使用已有稿件，或通过已配置的文案服务生成稿件。生成的建议不表示真实热榜。
2. **配音与字幕**：选择标准声音、已保存音色或已有音轨，取得口播字幕时间轴。
3. **素材与画面**：选择人物、上传素材或图文卡，按真实配音安排分镜。商品和素材混剪需要真实素材。
4. **字幕包装与成片**：HyperFrames字幕层与FFmpeg合成，再检查解码、音轨、时长、字幕及明显黑屏。
5. **封面与发布**：准备独立封面与发布资料；用户确认后上传，核对提交结果后结束。

发布后不采集自己作品的播放、点赞、评论或粉丝数据，不触发复盘和下一轮创作。保留登录、上传处理、提交或审核结果的必要观察，避免把窗口打开或按钮点击当作发布成功。提交结果不明确时保留记录，禁止自动重发。

前置“口播参考库”整理口播脚本、开头钩子、讲述要点与画面线索，供选题和写稿使用。它是创作前的可选资料库，不增加五步中的必填动作；使用已有文案仍可直接成片。来源和竞品互动信息仅用于前置调研，与发布后的运营采集分开。

## 口播脚本与画面线索

参考库默认使用“通用口播”模板，也可选择餐饮、美业、教培或本地生活模板；城市留空表示不限，行业标签可自行填写。模板影响口播筛选和行业线索整理，不自动添加来源，也不表示已连接平台热榜。客户只需选择模板、提供可公开读取的参考链接，再保存设置；无需编辑采集器 JSON。

“更新与筛选设置”默认要求口播正文至少 80 字，并优先参考实际取得的高评论内容。长度阈值和评论优先可调整；短摘要及不符合条件的内容保留来源记录，过滤条数与原因会显示，只有符合条件的口播参考进入自动写稿。旧记录仍可查看，缺少新拆解字段时展示原文及来源。

每条记录展示开头钩子、讲述要点、画面线索、素材标签与原文来源。画面线索是由原文整理出的检索和剪辑建议，不代表已经下载视频、识别画面或取得可用素材授权。公开页仅有摘要时不冒充完整口播转写；完整视频文案仍可通过原有文案提取工具导入。

点赞、评论和收藏只展示公开页实际提供的数字，未知显示“未取得”，不会补成 0，也不会把缺少热度证据的参考称为爆款。无来源时自动更新保持关闭；来源要求登录、验证码或没有公开正文时暂停并提示人工核查，不承诺无需登录取得完整抖音数据。

## 文件和资料

标准知识讲解仅需要文案，无需先上传人物、样音或图片。数字人需要可用的人物视频档案；克隆声音需要已保存且可用的音色。上传样音本身不代表本地声音训练已完成。

导入资料不会覆盖原文件，作品各阶段保存输入与生成结果。上传素材的名称可以帮助匹配，例如“厨房”“商品正面”“步骤演示”。当前本地匹配基于文字与文件名，不是视觉内容识别，也不自动搜索真实平台热门视频。

## 恢复与修改

后台任务与作品结果分别保存。关闭页面不删除任务，重新打开可以查看作品进度。程序中断后保留已生成的文件，再运行时复用有效结果。修改文案、声音或素材会使受影响的后续步骤需要重新生成；修改独立发布标题和封面不重做音视频。

已发出的收费请求如果结果不明确，作品等待核查，不自动重复调用。普通重试不能绕过此状态。此规则不能替代供应商的任务查询或完整的账户额度系统。

## 检查范围

自动检查覆盖可播放文件、音轨、配音时长、字幕范围、明显静音和全黑画面。检查通过不等于事实正确、素材已获授权、数字人口型自然或平台审核通过，仍需要成片预览。

基础画面是中间结果，仅在分镜预览显示。渲染未完成或质检未通过时，不会显示成片下载或发布交接。任务完成后停止定期重绘，让试听、播放与滚动保持稳定。

HyperFrames 组件位于 `creator-hyperframes`，Python 接口位于 `app/services/creator/hyperframes.py`。它使用独立本机 Playwright Headless Shell 和授权中文字体渲染 HTML 字幕，FFmpeg 将透明字幕层与实际画面合成，不使用客户的账号浏览器资料。首次启动准备需要的浏览器组件，制作时复用已核验的独立缓存；页面检查和视频渲染分别检测能力，不把可打开普通网页误当作能渲染成片。制作过程中不自动下载模板、字体或第三方 Skill；浏览器路径与安装方式以该组件说明为准。旧 `creator-renderer` 源码保留，当前制作流程不再调度它，也不会在 HyperFrames 失败后自动改用 Remotion。

## 人物动作与完整配音

「人物＋图文」按实际语音时间轴选出开头、中间、结尾的人物镜头，人物动作只顺序使用一次；其余时段优先穿插匹配的上传素材，没有相关素材时以原文中文信息卡衔接。人物片段使用原音轨相应内容驱动口型，最终视频保留完整配音与全局字幕，不重新配音，也不截断尾部。短人物片段作为内部文件，不会冒充完整成片出现在人物历史中。

全程人物需要参考视频的实际画面足够长。默认动作素材用完就停止并提示，不通过循环补齐；明确勾选允许复用后才在整个参考模板用完时回到开头。每个口型处理片段使用下一段连续动作，避免过去每八秒从人物开头重置的问题。模板剪辑也会检查实际视频轨长度，长音轨不能掩盖画面不足。

已存在重复动作的旧视频不会被覆盖。可用原配音与人物重新生成混合版，原文件、人物资料和已保存音色保留。

## 后续能力

画面语义识别、按段局部渲染、商业账号额度、一体安装与更新，以及平台真实发布验收，将在这套统一作品流程上继续完善。前置竞品采集和参考库继续服务选题，不扩展为发布后数据闭环。
