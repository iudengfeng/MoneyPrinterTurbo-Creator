# 创作工作台

双击“启动数字人口播.cmd”打开软件。“数字人口播”默认展示四列首页，同屏编辑文案、制作口播、处理视频和准备发布。可切换浅色或深色主题，任务中心显示后台进度。“速片工厂”保留原快速视频制作。

## 四列首页操作

| 首页列 | 使用方式 |
| --- | --- |
| 01 IP深度学习 | 选择IP资料或参考库，打开视频链接并提取文案；编辑文章后撰写或改写。视频提取受平台和素材可访问性限制，AI写稿使用自己的文案模型配置。 |
| 02 口播制作 | 选择音色与语言，生成语音并试听；选择形象生成口播，或导入已有口播视频。数字人需要自己的可用Duix服务与人物素材。 |
| 03 视频处理 | 设置画面、字幕、关键词和背景音乐，再生成成片。预览区只在实际渲染完成后显示可下载的成片。 |
| 04 发布制作 | 编辑标题与标签，生成真实视频帧封面，选择账号并打开发布预览。预览固定视频、封面、文案和账号，逐账号确认后才上传。 |

抖音、小红书为当前已接入的平台；快手和视频号暂不可选择。定时按钮提供手动发布清单下载，不自动排队或到时提交。四列中的选择框、生成按钮和预览共用同一份作品，修改文案、声音或画面后，受影响的后续结果需要重新生成。

侧栏保留视频换人、文生图、图生图、文生视频、图生视频、混剪、素材和帮助。人物工具复用数字人工作台，混剪复用原剪辑工具，素材保存到当前作品；图像和视频生成需要配置对应服务，并使用速片工厂中的可用制作方式。导航名称不表示已经接入所有生成接口。

作品库、客户／品牌档案在左下方。原有账号定位、参考库、声音管理、数字人管理和发布中心通过工具窗口继续使用，旧作品与素材交接保留。以下五阶段说明对应内部作品流程和原有工具，不是首页的侧栏结构。

创作中心可选择视频目的：介绍产品或服务、推广活动、分享专业知识、展示案例或客户反馈、打造个人形象、用已有素材快速成片。选择已保存的客户档案后，补充本次内容和素材，再预览、导出或带到发布中心。

客户档案一次保存提供内容、目标客户、实际特点和期望行动，地址、价格、服务区域、专业领域等资料按客户类型补充。后续创作可以直接复用，既有作品保留自己的资料版本。每种目的有推荐和备选模板，示例只用于理解结构，不会替代客户的真实资料。

目标时长用于写稿篇幅，配音实际时长决定成片长度。已有文案仍按原配音处理；制作方式和更细的声音、画面设置可以在后面的设置中调整。

## 创作中心：五步完成一条作品

| 步骤 | 操作与结果 |
| --- | --- |
| ① 选题与文案 | 输入主题或现成文案；主题写稿使用已配置的文案服务，不代表真实平台热榜 |
| ② 配音与字幕 | 选择声音或已有音轨，识别口播与字幕时间轴 |
| ③ 素材与画面 | 数字人、上传素材与图文卡；用实际配音安排分镜 |
| ④ 字幕包装与成片 | HyperFrames字幕层与FFmpeg合成；检查文件、音轨、时长和字幕范围 |
| ⑤ 封面与发布 | 准备封面和资料，确认上传并核对提交结果 |

“一键成片”连续执行作品流程；“分步制作”可逐阶段查看和修改。两种模式共用作品设置、进度和结果，不需要重新上传已经保存的资料。主题模式需要文案模型配置；标准知识讲解使用现成文案时，可以不上传人物、样音或画面素材。

知识讲解没有匹配素材时使用中文信息卡；素材混剪、商品介绍必须上传真实图片或视频。当前匹配根据文件名和明确提供的标签选择素材，无法识别图片中的实际内容。未匹配的混剪或商品素材按上传文件轮换，重复使用与缺少匹配都会记录，需在预览中检查相关性。不会自动搜索实时热门视频，也不会把轮换描述成视觉语义理解。

作品保存在本机作品库。关闭页面不删除作品或正在当前进程运行的任务；程序中断后，重新运行作品会复用仍有效的阶段结果。修改文案、声音或素材会让受影响的后续阶段需要重新生成；修改独立发布标题和封面不重做音视频。已发出收费请求但结果不明确时等待核查，不自动重复调用。

当前自动流程止于发布准备，外部上传和提交仍在发布中心逐项确认。恢复与检查范围详见[一键成片与分步制作说明](creator-automation.md)。

## 原有独立工具

原有工具继续支持独立制作和素材交接；以下“下一步”指工具之间的交接，步骤编号指内部五阶段流程。

①中的“口播参考库”用于创作前整理口播脚本与画面线索。默认通用口播模板，还可切换餐饮、美业、教培和本地生活；城市可留空，行业标签可自行填写。选择模板并提供公开参考链接后保存即可，不需要编辑采集器JSON，也不新增必填操作。原有手工导入保留。

每条参考显示开头钩子、讲述要点、画面线索、素材标签和原文来源。画面线索是文本整理出的检索或剪辑建议，软件没有因此取得原视频或可用素材授权。公开页只提供摘要时按摘要保留，不会声称已取得完整口播转写。旧参考仍可查看，没有新拆解字段时展示原文和来源。

高级设置默认要求正文至少 80 字，并优先参考实际取得的高评论内容。被过滤内容保留来源记录，但不送入自动写稿，页面显示过滤条数与原因。点赞、评论和收藏未知时显示“未取得”，实际 0 会显示 0；没有热度验证的参考不称为爆款。公开互动信息仅用于前置调研，发布工作流不采集自己的作品表现。

参考库不会自动填写来源；空来源时自动更新关闭。遇到登录、验证码、访问限制或缺少公开正文会暂停并提示核查，不保证无需登录取得完整抖音内容，可改用自己有权提供的原文或音视频。

### 选题和文案

在①的页内工具打开“选题与文案”，可使用关键词选题页。输入行业或赛道，搜索自己的参考文案，或生成标注来源的AI创作建议。

参考文案支持手动粘贴和从已有口播提取记录导入。卡片上可以查看全文、仿写，或围绕选题原创。进入编辑页后，可选六种风格、设置目标字数和补充要求，生成后手工修改、保存、重新生成或下载。保存的稿件可在“我的文案”继续编辑。重新生成失败时保留已有稿件，生成期间的其他修改也不会被覆盖。

点击“确认文案，下一步配音”会保存稿件并把完整正文带到配音工具；也可以送到原视频制作页面。

“从抖音寻找真实选题”提供两条路径：

- 无接口时打开抖音网页搜索，选择作品并复制分享链接，返回后提取口播加入参考库。分享链接受平台登录、下载限制和有效期影响；解析失败时可上传本地视频或粘贴原文。
- 有开放平台应用时，在展开的连接设置中填写 Client Key、Client Secret 和数字设备 ID，并事先申请 `aweme.dy.video_search` 权限。官方接口最多读取前 5 页、100 条，再筛选近 30 天并按真实点赞排序。不是全平台爆款榜，也不推算播放量。接口提供原文时保存为参考，未提供时显示视频链接并提供口播提取入口。凭证留在本机配置，调用 token 仅缓存在内存中。

当前没有用户的抖音应用凭证，官方接口通过模拟响应验证；真实搜索授权尚未验证。

### 配音

左栏选择音色，右栏编辑文案和调整 0.8～1.2 倍语速。可试听前 80 字，再生成完整配音。短试听与正式配音独立保存，短试听不提供继续制作入口；正式音频支持试听、下载、“确认配音，下一步数字人”以及直接用于模板剪辑。切换工作步骤会保留当前会话里的待配音文字，成功音频可从历史记录恢复。

- Edge 中文标准音色无需 API Key，但需要联网。已实测晓晓音色生成可播放的完整中文配音。
- Duix 本机已有音色依赖本机 Duix、Docker 和现有语音引擎就绪。音色列表可读取；本机克隆配音还需原来的 ASR/TTS 容器，独立数字人口型引擎不包含这些语音服务。
- 上传音色支持保存清晰样音为本机待创建素材，之后在 Duix 中创建音色再刷新列表；选择 VoxCPM 模式则通过已有云端声音克隆接口，需要原配音设置里的 API Key 和模型 ID，样音和文案会提交给该服务。保存素材不会自动宣称已完成本机音色克隆。

当前三种接入只支持自然情绪，未提供手册里的多情绪控制。语速通过实际音频处理实现；最多支持 6000 字，长文按段合成后完整拼接，输出独立 WAV，不覆盖旧音频。

### 数字人

页面参考手册第 12～16 页：上传形象并命名，在人物库选择视频形象，试听所选完整配音，勾选“确认使用上面这份配音”，再生成口播视频。配音工具提供“确认配音，下一步数字人”入口，也可选择历史完整配音或上传本地音频。短试听不进入数字人制作；若音频对应的文案与最新编辑的配音稿不同，页面会提示。人物生成始终按所选音频中的真实内容、语速和停顿制作，不重复配音。

已有 Duix 人物库只读，新上传人物保存在本工作台的人物库。人物视频最长 2 分钟、500 MB；配音最长 10 分钟、128 MB。视频素材会实际验证并归一化，损坏文件单独提示，不误判为缺少 FFmpeg。

支持竖屏和横屏生成，输出保留完整原音轨的无字幕口播视频，可播放、下载并送到模板剪辑；剪辑衔接会清空之前的替换配音和字幕，避免旧音轨覆盖新成片。字幕由后续剪辑识别当前音频生成。

默认「人物＋图文」把人物安排在开头、中间和结尾，动作连续使用一次，其余时段用口播原文信息卡衔接，整段声音保持完整。全程人物默认禁止参考动作耗尽后循环；需要纯人物且参考视频较短时，可上传更长形象，或在高级设置明确允许整段模板复用。处理时每个片段都会接续下一段参考动作，不再每八秒从头重置。短人物中间文件不进入正式历史。

本机引擎需要 Docker Desktop 和 `duix-avatar-gen-video` 容器。缺少口型引擎时可运行 `scripts/creator/setup_avatar.ps1`，使用已核验摘要的官方镜像与现有共享目录；单独生成口型不需要 ASR/TTS。该脚本保留不同配置的已有容器，不自动覆盖用户部署。可用 `-Registry docker.1ms.run` 选择官方文档列出的国内镜像源，内容摘要保持一致。

人物库和配音准备不依赖 Docker。生成任务共用原融合服务的显卡锁，完成或失败后恢复原有容器状态；若程序异常中断自己的口型任务，页面提供“恢复数字人引擎”按钮，其他程序的恢复记录会单独提示。当前没有接入图片数字人、换装、换背景、美颜或剪辑气口。

本机已使用既有 Duix 视频人物与 7.32 秒完整配音，实际验证生成、下载和传入模板剪辑。人物页面、配音切换和导航保留也通过当时安装版本的浏览器检查；早期该阶段完成过 135 项 Python 检查，不是当前版本的测试总数。

### 模板剪辑

数字人口播成片可直接进入剪辑，也可选择历史口播或上传本地视频。页面参考手册第 18～20 页，左侧为素材和样式设置，右侧为预览与生成按钮。提供全自动、自定义两种方式，以及清爽口播、醒目观点、知识讲解、商务表达四种原创包装；卡片为样式示意，生成前预览原素材，完成后显示实际成片。

全自动会按所选样式处理画面和字幕，使用实际音轨进行本机 Whisper 识别，按照真实词时间显示自然短句和停顿；下载的 SRT 与画面字幕时间一致。发行包默认不加背景音乐，可以上传自己有权使用的音乐并调整音量或关闭。自定义可选择画面调色、字幕样式，以及最多五段图片或视频画中画的出现时间、位置和宽度。音乐循环并淡入淡出，画中画视频保持静音，主视频的口播声音始终独立处理。

支持竖屏、横屏和方形画幅，可保留完整画面或居中裁切铺满，可添加画面标题；字幕可自动识别、上传 SRT、保留视频已有字幕或不添加。默认保留原视频音轨，也可以使用新的完整配音；替换声音不会重新计算数字人的嘴型，更换口播内容应回到数字人工具重新生成。生成任务在后台运行，失败时保留上一份成片；成功视频和字幕可下载，成片进入标题和封面工具，再带入发布中心。没有发布账号时也能先准备素材，添加账号后再准备发布。

这里的调色和包装由本工作台完成，未接入达芬奇软件，也不提供实时热榜素材检索或按文案自动搜索匹配画中画。新创作中心另提供本地分镜素材匹配与基础视频合成，其文件名和标签匹配边界见上文。

已用真实 7.32 秒数字人口播完成 Whisper 识别、字幕与音乐合成，并实际验证标题和定时画中画。当时安装版通过样式切换、素材试听、跨步骤保留设置及发布前预览检查；早期该阶段完成过 171 项 Python 检查。标题主动清空和关闭音乐的选择也会保留。

### 标题和封面

页面参考手册第 22 页，左侧准备标题、正文、话题和封面样式，右侧预览成片与实际封面。模板剪辑工具会带入这条成片对应的字幕原文，不使用另一条视频的配音稿；也可选择历史成片、上传视频并提取文案，或自行填写口播文字。

“生成标题”使用已有文案模型生成三个候选标题、正文、话题和封面标题，全部可手工修改。没有接口或生成失败时仍可手工准备；已有内容和封面不会被失败任务覆盖。话题只是创作建议，不代表平台热榜。

封面从所选视频的真实时间点截取画面，提供四种本机原创排版，支持竖屏、横屏和方形图片，也可上传自己的封面。标题自动缩排以完整展示，生成图片可下载；修改封面设置后会提示重新生成。素材保存为独立历史记录，可恢复并带入发布中心，不覆盖原视频。

已实测四种封面、三个画幅、120 字中文与中英文排版，以及完整的生成、下载、保存和发布前预览流程。早期该阶段完成过 209 项 Python 检查；标题接口使用自编通用测试文字调用已有 DeepSeek 设置验证，未向接口发送本机字幕或视频。

### 发布中心

从标题和封面工具带入成片、标题、正文与话题以及封面，也可恢复历史发布素材或上传本地视频。实际检查视频时长、画幅及封面是否可读，损坏媒体会单独提示。没有发布账号时仍可查看视频、编辑文案，并导出包含视频、封面和文字的本地 ZIP 素材包，用于自行上传。

账号卡片分别保存抖音、小红书账号备注；打开专用浏览器后由用户扫码登录，点击“检查登录状态”核对当前创作者页面，再关闭登录窗口。打开窗口不会直接标为已登录，安全验证会显示需要处理。关闭后保留此前核对记录，发布前仍会检查当前页面；各账号浏览器目录独立保存在本机。

选择发布账号后，可分别编辑每个账号的标题、正文与话题。创建预览只把当前内容保存到本机；视频和封面按文件内容复制保存，之后修改上方文字或换素材不会改变已有预览。每个预览都显示实际文件与独立文案，必须逐项点击“确认发布到该账号”才会开始浏览器发布任务。

发布任务通过已配置的文本模型、Playwright 和 MCP 操作平台表单。确认发布时，页面观察与该任务的标题、正文会交给配置的模型判断下一步；本地预览、导出素材及登录检查不会调用该模型。平台表单如要求调整文字长度，会保留完整内容并提示处理，不自动截断。账号正在登录或排队发布时禁止同时处理；重复点击不会再次排队。提交结果待核查时不提供直接重发，应先检查平台作品列表。

发布是作品链路的终点。程序只保留登录检查、上传处理、提交或审核结果核对所需的页面观察，不进入数据中心、数据分析或评论运营页，不采集本条作品的播放、点赞、评论或粉丝表现，不在提交后继续触发创作任务。作品列表可用于核对本次提交结果，提交未知状态和历史账号记录会保留。

当前接入抖音和小红书。本地素材流程和浏览器工具协议可以独立验收，首次真实平台发布仍需要扫码登录、人工确认，并检查实际页面与平台返回结果；平台审核与提交成功分别记录。

早期六工具阶段完成过 251 项 Python 检查，其中发布后端 30 项、发布界面 21 项；浏览器策略 11 项通过。这些是阶段记录，不是当前版本的测试总数。实际 MCP 工具连接、本地模拟发布和登录状态变化均已验证。浏览器中实测成片播放、标题封面交接、跨页保留编辑、独立账号文案、预览不随后续编辑改变及 ZIP 内文件与原素材一致；这些本地检查不代表真实账号已发布。

2026-10-04 已实测用户扫码后的抖音登录复用及官方上传页识别，工作台取得当前已登录的真实证据。登录入口需要打开时，只在官方页面点击一次文字明确的登录按钮或链接；状态诊断只保留固定公开控件名称与角色。未填写、上传或提交任何作品，首次真实发布仍需用户确认素材预览。

## 其他已有入口

- 文案提取：上传音视频或粘贴分享链接；Whisper 标准模型已缓存，使用 CPU 转写。文案可编辑、保存、导出并送入原制作流程。损坏媒体和没有音轨会单独提示。
- 账号选题：保存行业、受众、账号定位与参考文案，生成选题并继续写口播稿。使用原基础设置中的文案模型。
- 声音与数字人：收藏本机 Duix 音色，或上传样音使用已有 VoxCPM 云端克隆；云端克隆需要对应 API 配置。本机新音色仍在 Duix 中创建。数字人口播复用现有融合引擎与模型。
- 模板剪辑：从侧栏“混剪”打开剪辑工作台，旧模板接口继续兼容；数字人任务提供无字幕编辑源，避免重复字幕。
- 发布中心：先保存抖音/小红书账号备注并扫码登录；选择成片、封面和文案，创建预览，再确认发布。每个平台使用独立任务。结果未确认时系统阻止重复提交。首次真实平台发布需要检查实际页面和结果，平台审核单独记录。

任务在后台排队，页面关闭不影响当前进程中的任务。程序重启时旧独立工具的未完成任务会标为中断；新创作中心的作品阶段结果另行保存，可重新运行并复用有效结果。发布记录保留，提交结果不明确时需先核查平台作品列表。数据位于 `storage/creator`；声音样本与浏览器登录目录保留在本机。代码和依赖分别位于 `app/services/creator`、`creator-hyperframes` 和 `creator-browser`。旧 `creator-renderer` 保留源码，当前渲染不再运行该 Remotion 组件。

后续更新原项目可能覆盖页面入口；升级前保留当前增强版或开发分支。Node 依赖固定在各组件的 package-lock.json，Python 新依赖固定在 creator-requirements.txt。
