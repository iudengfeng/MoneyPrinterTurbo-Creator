# Creator 更新记录

## creator-v2026.10.08.3

四列首页新增“一键成片／分步制作”。一键模式顺序完成前置阶段、视频与本地封面／发布资料；分步模式先生成成片。外部平台上传与发布仍需单独预览、逐账号确认。

导入已有口播视频可自动识别缺少的文案，保留原视频连续画面，并隔离切换作品后的识别结果。无声视频提示先提供文案或配音，不用假转写填充。视频预览新增放大播放与真实文件下载。720P 为当前可用分辨率，其他预设保持显示但暂不可选择。

浅色布局保留参考图的四列与渐变卡片；深色主题补齐顶部、侧栏、输入、空预览和弹窗配色。旧作品、客户档案、服务配置与声音／人物素材继续在本机保留。

本轮首页、异步状态、作品流程、启动与发布边界检查合跑 99 项测试和 14 项子测试通过。隔离浏览器验证制作模式切换、禁用未支持分辨率、主题切换后文案保留及 1906／1440／1060 像素布局；测试没有调用付费生成服务或提交平台发布。

## creator-v2026.10.08.2

修复发布制作列中“定时发布”按钮因提示文本包装层被隐藏的问题。按钮恢复可见，仍用于下载手动发布清单，按所选时间自行发布。

测试使用临时合法音频和 Noto Sans SC 实际支持的字形，保留中文／英文真实绘制、缺字判断、音频解析与安全路径检查。背景音乐的默认预期同步为不加音乐；Windows 便携入口测试显式模拟随包 Python 3.11，并保留拒绝 Python 3.13 随包运行时的约束。

六个受影响测试文件在仅含 Noto 字体与 OFL 许可的隔离字体目录中合跑，143 项测试、58 项子测试通过，相关 Ruff 检查通过。验证覆盖字幕与视频服务、WebUI 默认值与设置迁移、Creator 成片渲染、Windows 便携入口；此结果仅代表该目标范围，GitHub 新版本 CI 尚未验证。

## creator-v2026.10.08.1

数字人口播首页改为四列工作台：**01 IP深度学习、02 口播制作、03 视频处理、04 发布制作**。同屏编辑文案、生成与试听语音、选择人物、处理字幕和音乐、预览成片以及准备标题与封面。保留浅色／深色主题、后台任务中心、原速片工厂、作品库与客户／品牌档案。

四列首页复用真实作品状态。内部仍保存文案、声音、画面、成片、发布资料五阶段；中间画面和未通过成片检查的结果不会提供正式下载或发布入口。HyperFrames的页面检查与视频渲染分别验证浏览器能力，渲染使用通过实际成片检查的独立Headless Shell。

标题和标签使用用户已配置的文案服务；封面截取所选成片的真实画面并在本机排版。发布先保存固定视频、封面、文案和账号的预览，逐账号确认后才开始上传。当前接入抖音、小红书；快手和视频号保持不可选择。定时按钮下载手动发布清单，没有创建自动发布任务。

Windows ZIP采用轻量联网启动方式。完整解压后双击“启动数字人口播.cmd”，首次联网准备独立Python、Node、媒体工具和浏览器。标准TTS需要联网，AI写稿需要用户自己的服务配置；数字人和声音克隆需要用户自己的可用Duix部署、素材及硬件。本包不包含个人API配置、账号登录资料、客户照片、声音样本或模型权重。字体仅提供Noto Sans SC与OFL许可，背景音乐默认不加。

本版验证包括64项首页与接口测试、36项HyperFrames相关测试，以及47项真实Noto字体和中文卡片／封面测试；字体检查也在仅含Noto与OFL、没有个人配置的隔离副本中通过。三秒、720×1280、90帧的真实HyperFrames成片验证覆盖透明字幕层、配音和背景音乐。各组测试范围有重叠，不作为全项目测试总数。发布测试使用隔离素材与模拟账号，没有上传或提交用户作品；全部AI服务和真实平台发布仍需各自验收。

安装与数据迁移见[Windows安装说明](creator-install.md)，操作方式见[四列工作台说明](creator-workspace.md)。升级前备份自己的`config.toml`与`storage/creator`，建议解压到新目录后按需迁移。
